\# Contributing to Tesserae



Thank you for your interest.



\## What We Accept



\- Language skins (`strings/community/` folder)

\- Plaintext pieces (`plaintext/` folder)

\- Use case tests (car, art, space, etc.)

\- Documentation improvements

\- Bug reports



\## What We Do NOT Accept



\- Changes to CLM logic (safety fence)

\- Changes to Onion snapshot format

\- Changes to core architecture or North Star



\## How to Contribute



1\. Fork the repo

2\. Create a branch

3\. Add your contribution

4\. Submit a pull request



\## License



By contributing, you agree to license your contribution under:

\- MIT for code

\- CC BY for Plaintext pieces and language skins



Thank you for helping build structured inquiry for everyone.
